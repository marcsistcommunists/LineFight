# Napoleonic Wars: Dynamic Campaign

Пошаговая стратегия в сеттинге Наполеоновских войн с элементами RPG для полков.

## Описание игры

### Сеттинг
- Эпоха Наполеоновских войн
- Линейная пехота, мушкеты, штыковые атаки
- Исторические города и местности

### Геймплей
1. **Глобальная карта**: Перемещение армий между областями (городами, регионами)
2. **Система полков**: Каждый полк имеет уникальные характеристики, название и инвентарь
3. **Пошаговые бои**: Тактические сражения на сетке 16x16
4. **Перманентная смерть**: Уничтоженный полк исчезает навсегда (с показом специальной сцены)

### Особенности
- Инвентарь полка: оружие, знамя, бонусные предметы
- Влияние местности на бой (лес, холмы, река)
- Система морали и опыта
- NSFW контент при поражении полков

## Классы и их ответственность

### Сущности (entities)
- **Regiment**: Полк с характеристиками (HP, мораль, урон, дальность, движение)
- **Army**: Контейнер для полков, перемещается по карте
- **Item**: Предмет экипировки с бонусами
- **Inventory**: 3 слота (оружие, знамя, аксессуар)

### Мир (world)
- **Province**: Область с типом местности, владельцем, армией
- **WorldMap**: Граф областей, управление перемещениями

### Бой (battle)
- **BattleManager**: Логика пошагового боя, расчет урона
- **BattleUnit**: Обертка над полком для тактики
- **BattleTile**: Клетка 16x16 с особенностями местности
- **BattleAction**: Действия (перемещение, атака, ожидание)

## Технологии

- **Java 17+**
- **LibGDX 1.12.1** - кроссплатформенный игровой движок
- **Gradle** - система сборки

## Сборка и запуск

### Требования
- JDK 17 или выше
- Gradle 7.x или выше

### Команды
```bash
# Сборка проекта
./gradlew build

# Запуск игры
./gradlew :desktop:run

# Очистка
./gradlew clean
```
